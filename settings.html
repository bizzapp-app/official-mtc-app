🔒 Production authentication

Supabase Auth is the only login system. Demo accounts and local password stores are disabled.
The administrator creates all staff and student portal accounts below. The administrator account itself is bootstrapped directly in Supabase. Each account is a real Supabase Auth user and works on any device. Credentials are configured with environment variables (VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY), not browser storage.
